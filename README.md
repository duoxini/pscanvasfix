# PsCanvasFix

用于 ColorOS 平板新版分屏画布的 LSPosed 模块：在 260608 的 `com.oplus.pscanvas`
上恢复旧版 502 的三分屏与全景交互。

## 来源

ColorOS 金标版本改用了"三等分"画布逻辑，与 502 版体验不一致；
且其任务边界（1113/1685px）与 502 宽画布（1600px 列宽）不一致，导致三分屏出现
上下/左右黑框。

## 目的

- 普通三分屏恢复 502 横向宽画布：左侧两个完整竖屏窗口 + 右侧露出第三个（2+1），
  三个任务内容铺满、无黑框；
- 五指捏合从 2+1 进入全景（三窗口屏幕内完整显示）、单击不退出全景、向外放大回
  普通分屏；
- 二分屏保持 OEM 原生行为。

## 适配版本

- 主适配：`260608`（OplusFlexibleWindowUI v2.0.0，versionCode 20）
- 同级验证：`260403`、`260512`（4 代际离线解析测试通过）
- `251215`（旧版逻辑）不在支持范围，模块自动跳过
- 采用 DEX 结构扫描做能力驱动符号解析，不依赖 SHA / 版本白名单

## 使用

LSPosed 中启用本模块，作用域设为 `com.oplus.pscanvas`，重启目标应用生效。

最新版本：[v1.3-260608](https://github.com/duoxini/pscanvasfix/releases/tag/v1.3-260608)
