# PsCanvasFix

用于 ColorOS 平板**金标版系统**的 LSPosed 模块。

金标版系统中的多窗口组件 `com.oplus.pscanvas` 调整了三分屏与画布交互逻辑，部分旧版多窗口体验被移除或改变。本模块用于恢复其中的经典三分屏与全景画布行为。

## 功能

- **恢复经典 2+1 三分屏布局**
  - 左侧显示两个完整竖屏窗口；
  - 右侧保留第三个窗口的部分预览；
  - 恢复旧版横向宽画布体验。

- **恢复三应用全景模式**
  - 在 2+1 三分屏状态下，通过五指捏合进入全景；
  - 三个应用窗口完整显示在屏幕范围内；
  - 全景状态下单击窗口不会直接退出；
  - 五指向外放大可返回普通 2+1 三分屏。

## 适配范围

已验证版本：

```text
versionDate=260403
versionDate=260512
versionDate=260608
```

模块**不依赖版本号或 APK SHA-256 白名单**。

运行时会直接扫描 `com.oplus.pscanvas` APK 的 DEX 结构，并根据目标类、方法签名及能力特征动态识别 Hook 位置。

因此，对于仍保持相同或相近内部语义结构的其他版本，也具备一定的自动兼容能力。

> 系统更新可能导致内部实现发生变化。若功能异常，建议提供多窗口组件版本信息及模块日志用于分析。

## 使用方法

1. 安装模块；
2. 在 LSPosed 中启用 **PsCanvasFix**；
3. 将作用域设置为：

```text
com.oplus.pscanvas
```

4. 强制停止或重启目标多窗口组件后生效。
