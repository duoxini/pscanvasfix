# PsCanvasFix

用于 ColorOS 平板**金标版系统**的 LSPosed 模块：其多窗口组件（`com.oplus.pscanvas`）
改用了新的三分屏/全景画布逻辑，与旧版体验不一致，并存在分屏黑框问题。

## 来源

金标版系统（多窗口组件 v2.0.0）重写了三分屏与全景的画布逻辑，且部分任务边界与
宽画布槽位不一致，导致普通三分屏出现上下/左右黑框、全景交互与旧版不同。

## 目的

- 普通三分屏恢复旧版横向宽画布：左侧两个完整竖屏窗口 + 右侧露出第三个（2+1），
  三个任务内容铺满、无黑框；
- 五指捏合从 2+1 进入全景（三窗口屏幕内完整显示）、单击不退出全景、向外放大
  回普通分屏；
- 二分屏保持系统原生行为。

## 适配范围

- 适配：**金标版系统**（改动多窗口逻辑的版本）；
- 非金标系统保持原生逻辑，模块自动安全跳过，不改变其行为；
- 模块直接从多窗口组件 APK 做 DEX 结构扫描识别能力（不依赖版本号/哈希白名单），
  对仍保持同语义架构的版本自动兼容。

## 使用

LSPosed 中启用本模块，作用域设为 `com.oplus.pscanvas`，重启目标应用生效。

最新版本：[v1.3-260608](https://github.com/duoxini/pscanvasfix/releases/tag/v1.3-260608)

## 版本适配规则

目标 APK 按代际区分（所有代际的 versionName/versionCode 均为 `2.0.0/20`，
只能用 SHA-256 / DEX 结构识别）：

| 代际 | 角色 | 说明 |
|---|---|---|
| `251215` | **502 原版基准（仅对照）** | 两套逻辑中的原版逻辑：二分屏/三分屏/全景正确、无黑框。**只作为版本对照放在 `archive\file`，不安装、不测试**。所有需适配版本的适配目标 = 对齐 251215 原版行为。 |
| `260403` / `260512` / `260608` 及以后新版本 | **需适配版本** | 金标版系统的另一套（700 新）逻辑，由模块按能力解析自动适配回 251215 原版行为。 |

适配流程（真机验证约定）：

1. 新版本 APK 放入 `archive\file`，按 `多窗口(<代际>).apk` 命名；
2. 确认设备当前版本（`adb pull` 设备 APK 后比对 SHA-256）；
3. **排除 251215（不装）与本机版本**，其余需适配版本按代际顺序
   `adb install -r -t` 覆盖安装，每装一个版本由用户手动测试，
   以 251215 原版行为为对照；
4. 发现差异 → 按能力组定位适配 → 修复后重测该版本。
